# pose-text-feedback-thesis
Experimental code for my MSc thesis on 3D pose analysis and corrective feedback (EC3D, AIFit-style signatures, mini CLIP).


Questo repository contiene il codice sperimentale per la mia tesi magistrale su analisi di pose 3D e feedback correttivo testuale.
Prima milestone: baseline su EC3D con classificazione degli errori, firma tipo AIFit e primo tentativo contrastivo pose↔testo.
